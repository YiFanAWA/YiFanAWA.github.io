# YiFanAWA.github.io

刘一帆（Yifan Liu）的个人主页：<https://yifanawa.github.io/>

- `index.html`：主页。精选项目、全部仓库与最近动态；仓库和动态在打开页面时从 GitHub 公开 API 实时读取，读取失败时显示内置快照。
- `old-home.html`：旧版主页。
- `exhibition.html`：《浮光》视觉实验页。
- `chap-02/`：WebGL 图形学课程实验。

单文件静态页面，不需要构建。本地预览：`python3 -m http.server 8000`，然后打开 <http://localhost:8000/>。
